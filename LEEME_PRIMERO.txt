REQUISITO:
Tener instalado Python 3.10 o superior (https://www.python.org/)
* Asegurate de marcar la casilla "Add python.exe to PATH" al instalarlo.

------------------------------------------------------------------------
OPCION 1: INICIO EN 1 CLIC (RECOMENDADO)
------------------------------------------------------------------------
Haz doble clic sobre el archivo:
iniciar_sistema.bat

El script se encarga de:
1. Crear el entorno virtual si no existe.
2. Instalar los paquetes necesarios (requirements.txt).
3. Conectar la base de datos precargada.
4. Abrir el sistema en tu navegador.

------------------------------------------------------------------------
OPCION 2: DESDE VISUAL STUDIO CODE
------------------------------------------------------------------------
1. Abre VS Code.
2. Menu: Archivo > Abrir carpeta... y selecciona esta carpeta.
3. Presiona F5 (ya esta configurado en .vscode/launch.json).
   O abre la terminal con Ctrl + Shift + ` y escribe:
   .\iniciar_sistema.bat
